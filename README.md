## Getting Started

1. Install dependencies:

```bash
npm install
```

2. Create your local environment file from the example:

```bash
cp .env.example .env.local
```

3. Update the values in `.env.local` if your backend or image host differs from the defaults.

4. Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

If the app is missing data or images on another machine, the most common cause is that `.env.local` was not created or the required API URLs were not set.

This project uses [`next/font`](https://nextjs.org/docs/basic-features/font-optimization) to automatically optimize and load Inter, a custom Google Font.
